# 📚 Bootstrap Dashboard — Biblioteca Digitale

Questo progetto consiste nella realizzazione di una **dashboard responsive** per la gestione di una biblioteca digitale.  
L’interfaccia include:

- 📕 Catalogo libri  
- 👤 Anagrafica utenti  
- 📜 Storico prestiti  
- 📝 Sezione Todo  
- ❓ Sezione FAQ  
- ➕ Form di inserimento nuovo libro  

Il layout è realizzato utilizzando **Bootstrap 5**, sfruttando componenti, utilities e sistema a griglia.

---

## 🚀 Obiettivo del progetto

Ricreare una dashboard moderna e responsive e mantenendo un codice ordinato, accessibile e basato sui componenti Bootstrap già disponibili.

---

## 🛠️ Tecnologie utilizzate

- **HTML5**
- **CSS3**
- **Bootstrap 5.3**
- **Font Awesome 6**
- **Responsive design** tramite classi Bootstrap

---

---

## ✨ Funzionalità principali

### 📑 Catalogo Libri
- Tabella responsive con elenco dei libri
- Stato: **Disponibile**, **In prestito**, **Non disponibile**
- Azioni disponibili: ✏️ Modifica — 🗑️ Elimina
- Colonne adattive (es. Data Prestito mostrata solo da *md* in su)

### 📝 Todo List
- Lista attività con checkbox
- Stilizzata tramite componenti **Bootstrap List Group**

### ❓ FAQ
- Implementata con **Bootstrap Accordion**
- Contenuti espandibili/collassabili

### ➕ Form Nuovo Libro
- Campi autore, titolo, genere, anno, ISBN
- Campo note
- Checkbox “Disponibile anche in digitale”
- Pulsante per confermare l’inserimento del libro

---

## 📱 Responsive Design

La dashboard è completamente responsive grazie a:

- Sistema a griglia Bootstrap
- Classi come `col-`, `col-sm-`, `col-md-`, `d-sm-none`, `d-md-block`, ecc.
- Navbar collassabile
- Tabelle e card adattive
